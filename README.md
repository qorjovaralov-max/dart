# 40-maktab Quiz (Viktorina) 🎯

Bu loyiha 40-maktab o'quvchilari uchun mo'ljallangan qiziqarli va interaktiv viktorina (quiz) veb-ilovasi.

## 🚀 Ishlatilgan texnologiyalar
* **HTML5** – sahifa tuzilmasi uchun
* **CSS3** – dizayn va bezaklar uchun
* **JavaScript (ES6)** – o'yin mantiqi va savollar tizimi uchun

## 💻 Loyihani ishga tushirish
Loyihani o'z kompyuteringizda sinab ko'rish uchun:
1. Ushbu repository'ni ko'chirib oling (clone qiling) yoki ZIP formatida yuklab oling.
2. `index.html` faylini istalgan brauzerda oching.
